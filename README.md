# MotionKit · JS 动效模板引擎 + 剪辑插件

一套跑在浏览器里的**动效模板引擎**，专门做视频里那种"科技感叠加层"：
HUD 细线框、卡点大字、终端面板、编号卡片、跑马灯、计数器、故障 / 扫描 / 网点转场……
全部是纯 JS + Canvas 绘制的，**零依赖、零安装、离线可用**。

它给你的剪辑流程补上四件事：

| 你想要 | MotionKit 怎么做 |
| --- | --- |
| **卡点** | 拖进一首歌 → 自动算出 BPM 和每一个拍点 → 图层自动吸附，还能"一键每拍铺一层闪白" |
| **出字幕** | 导入 SRT / ASS / VTT → 自动切短句 → 卡点字幕模板逐句弹出 / 逐词高亮 |
| **做转场** | 甩镜、冲击推近、镜头震动、闪白、百叶窗、网点升起、扫描带、故障爆闪、遮幅推入、色散 |
| **视觉特效** | 颗粒、扫描线、色差、故障切片、暗角、辉光、像素化、VHS、数据摩什、反相闪光 |
| **剪素材** | 时间轴上一条条片段：视频 / 图片 / 音频都能挪、裁、切、复制、删，导出的 MP4 就是你剪出来的样子 |
| **调画面** | 每段都能变速、调色、缩放摆位（多轨叠加做画中画）；转场、交叉淡入淡出 |

做好的东西可以导出成**带 Alpha 的 PNG 序列 / WebM / MP4（直接出片）/ ProRes 4444**，
直接拖进 Premiere、剪映专业版、达芬奇、AE 当叠加层用；也可以让 ffmpeg 直接烧到你的成片上。

### ⚡ 一键铺满（先铺后改）

不想一上来就全自动？AI 助手面板里第一个按钮就是 **一键铺满**：
它先花几秒粗看一遍素材（亮度 / 运动量 / 镜头切点 / 卡点），

- 全程一条 HUD 底噪（保证不留空）

  长镜头→终端面板、亮且静→吊牌/编号卡

铺完**自动载进工作室**，你在这基础上删多余的、改文字、拖位置。
和「开始生成」的区别：它不转写语音、不叫大模型，**几秒出结果**，目标是"先铺满、人来精修"。

### 方式一：双击 `启动工作室.bat`（推荐）

它会起本地服务（开发模式）并**自动用 Chrome / Edge 打开工作室**，关掉就按窗口里的 Ctrl+C。
**AI 助手只有这个模式才有**，所以推荐一直用它。

顺手做的两件事：检查 Node / Python / faster-whisper 并在启动时告诉你缺什么；
重复双击不会起第二个服务——它会认出已经在跑的那个，直接把页面打开。

### 方式二：离线单文件版（没有 AI 助手）

直接双击 `dist/studio.html`。模板、卡点、字幕、导出全都在，只是没有 AI 助手。
**必须用 Chrome 或 Edge**：默认浏览器是 360 / QQ / 搜狗之类的话大概率白屏，
右键 `dist/studio.html` → 打开方式 → Google Chrome。

好处是零依赖、不占端口、可以拷到任何机器上跑。

### 方式三：命令行 / 改源码（改完即时生效）

```bash
npm run studio              # 起服务，手动打开 http://localhost:5178/studio/index.html
node tools/serve.mjs --open # 起服务并自动开浏览器（bat 里用的就是这个）
```

> 为什么开发模式需要服务器：源码是 ES Module，浏览器不允许 `file://` 直接加载模块；
> AI 助手还要调 python / ffmpeg / 无头浏览器，得有个后端转手。
> 改完源码跑 `npm run bundle` 重新生成 `dist/studio.html`。

### 然后

1. 把**视频**拖进中间的画面区（或者什么都不放，纯做叠加层）
2. 把**音乐**拖进去 → 自动分析出 BPM 和拍点，时间轴出现一条条卡点线
3. 左边模板库**按住一个模板拖到画面里**放下 → 图层加进来了（拖到哪儿就摆在哪儿的
   位置参数上），再在右边调参数
4. 加字幕：`导入字幕` 选 `.srt`，会自动挂一个"卡点字幕"图层
5. 右上角 `导出…`

> **工程会自动保存。** 改了什么都会存在浏览器本地，图层、参数、特效、字幕、卡点、
> 你在预览里摆的位置全都在。刷新页面、关掉浏览器、第二天再打开，都会自动接着上次继续。
> 要用别的机器 / 发给别人 / 手动留底，才需要点顶栏的 **保存工程** 存成 JSON。
> 想从空白开始：顶栏 **新建**，或者恢复提示条上的 **丢弃**。

> **两台电脑轮着开发？** 顶栏还有 **⇅ 同步**：点按钮就完成 提交 / 上传到 GitHub /
> 拉取更新，也能一键打包成 zip 免网络拷到另一台机器（同一个面板里还能复制 SSH 公钥）。
> 按钮都在 [docs/命令速查.md](docs/命令速查.md) 里写了，全程不用敲命令。

### 框选 + 一次删掉一批

不想要的图层不用一个个点着删：

- **预览里在空白处拖** = 框选，框到的图层一起选中（其余的一起变青色虚线框）
- **时间轴上 `Shift` + 在空白处拖** = 框选一块区域里的图层（不按 Shift 拖动还是原来的拖播放头）

是青色虚线框，在时间轴上整条压暗高亮，主选（参数面板认的那层）还是原来的橙色框加手柄。

## 卡点

### 卡点重复动效：整组改，不用一层层删

「一键铺满闪白」一铺就是十几个甚至几十个图层，之后想调就只能一个个删？不用了。
右边 **卡点** 页签下面有 **卡点重复动效（整组改）**：

| 控件 | 作用 |
| --- | --- |
| 强度 | 拖一下，**全部**闪白的峰值立刻跟着变 |
| 渐入 | 整组改淡入速度（闪白是"啪"地一下还是柔和一点） |
| 单次时长 | 全部一起变长/变短（贴到工程末尾的会自动截断） |
| **随机差异** | 0 是整齐划一，拉大之后每一记闪白的强度和时长都略有不同，**去机械重复感** |
| 频率 | 每拍 / 每 2 拍 / 每 4 拍 —— 换一档就**按新频率重铺**，不用手动加删 |
| 按当前设置重铺 | 用现在的强度/时长重新铺一遍（改过 BPM 之后尤其有用） |
| 全部关掉 / 全部打开 / 清空 | 一眼看出"关掉闪白"和"彻底不要"的区别 |

一共四组，面板上直接写着各有几个：**闪白硬切**、**冲击推近**（多了旋转和拖影两个整组参数）、
**卡点大字**、**卡点字幕**。

文字类是另一种处理：它不会清空重铺（那样文字就没了），而是**保留各自的内容、只按新频率重排时间**
（`按频率重排`），多出来的自动关掉而不是删掉。字幕组只给字号，因为字幕轨通常就一层。

这些批量铺出来的图层带 `group: "beat"` 标记，跟着工程一起存，换台电脑打开也认得出。

![卡点重复动效整组改](docs/preview-beatfx.png)

这是整套东西的核心。

拖入音频后，浏览器里会做一次真正的节拍分析：

1. STFT 求**分频段谱通量**，低频（底鼓）权重最高，高频（镲片）压下去
2. 对数压缩，避免低频瞬态把一切淹没
3. 自相关估周期，带 100–140 BPM 先验，避免半拍 / 双拍歧义
4. **最小二乘把拍点网格拟合到实际起音峰**——这一步是精度关键，
   能把 hop 带来的量化误差平掉。实测 128 BPM 的素材算出 128.01
5. 按 4/4 找强拍（第一个"1"）

得到的拍点会以竖线画在时间轴上（青色更粗 = 强拍），同时：

- 新加的图层自动吸附到最近的卡点
- 右边"卡点"分组可以改 BPM / 偏移
- **一键卡点铺满（闪白）**：每个拍点叠一个短闪白图层
- **每 2 拍铺一个推近**：两拍一个冲击推近

> 没有音频也行：默认 120 BPM，手动改 BPM 和偏移照样能卡。

命令行侧有一份等价实现：

```bash
python tools/beatmap.py --in music.mp3 --out beats.json --markers beats.txt --fps 25
```

`beats.txt` 可在 Premiere 的**标记面板 → 导入标记**，时间轴上就出现一条条卡点。

## 字幕

支持 **SRT / WebVTT / ASS(SSA)**。导入后：

- 自动挂一个 `卡点字幕` 图层（如果还没有的话）
- `把当前字幕切短句` 会按标点切成 ≤12 字的短块，并**按字符数分配时长**，用来做"逐句弹字"
- 有音频分析结果时，会给每条字幕估算**词级时间**，`karaoke` 样式即可逐词高亮

| 样式 | 效果 |
| --- | --- |
| `bar` | 黑条 + 白字，最像纪录片字幕（默认） |
| `mono` | 等宽小字，终端感 |
| `hero` | 超大居中 + 橙色短线，适合喊口号 |
| `karaoke` | 逐词从暗到亮（需要词级时间） |

### 字幕换装：一句台词一个样子

一条 `卡点字幕` 从头铺到尾，整片都是同一个样子。字幕面板里的**字幕换装**把每句台词
交给一个已有的设计模板来演 —— 池子里现在有 **19 种样子**（黑条字幕 / 等宽 / 逐词高亮 /
注释气泡 / 跑马灯条 / 终端面板 / 编号卡片 / 胶带标签 / 卡点大字 / 标题定格 / 词块宫格 /
索引标注 / 名字条 / 吊牌 / 压扁大字 / 竖排大字 / 杂志标题 / 摇滚大标题 / 系列编号）。

![字幕换装：六句台词六个样子](docs/preview-caption-styles.png)

> 上面这排是 `presets/slopcore-captionstyles.json`：同一份 12 秒工程，
> 六句台词分别用跑马灯、词块宫格、索引标注、编号卡片、注释气泡、吊牌来演。

怎么用（工作室 → 右栏「字幕」页）：

1. **换装风格**：`字幕感`（贴着成片字幕的观感）/ `混合`（推荐）/ `海报感`（夸张，偶尔来一记）
2. **提前量**：图层比台词早起多少秒，默认 0.15
3. 点 **给每句字幕换模板** —— 不满意就 **换一批（重新洗牌）**，想回到一条字幕条就 **清掉换装**

它的取舍是明写在规则里的，不是随便挑一个：

- 用量少的先用：**一轮用完之前不会重复**，也不会出现某几个样子被反复用、另外几个从不露脸
- **连着两句不许撞样子**
- 每个样子自己声明"我这行最长放得下几个字"：长句子自动跳过胶带标签 / 名字条 / 吊牌 / 竖排，
  免得台词被截成半句或者冲出画面

AI 自动剪辑（`agent/director.py`）走的也是同一套样子池，所以「AI 助手 → 开始生成」
出来就已经是换装过的。想离线生成一份可以看可以改的：

```bash
python tools/caption-styles-demo.py --scene presets/slopcore.json \
       --out presets/slopcore-captionstyles.json --tier mid --seed 3
```

### 整组改：40 句 40 层，改一个等于改全部

换装出来的每句台词都是独立图层（40 句就是 40 层）。字幕面板最下面的
**字幕换装（整组改）**把它们当一个整体调，和「卡点重复动效」是一个路子：

| 控件 | 作用 |
| --- | --- |
| 字号 × | 整组放大缩小。给的是**倍数**，因为各模板原始字号差着好几倍（字幕条 44、卡点大字 118），统一设成 60 会把一半样子弄坏 |
| 上下 / 左右位置 | 走图层自带的变换，19 种样子通吃（会覆盖单独拖过的那点偏移，这是故意的） |
| 不透明度 | 整组压淡 / 恢复 |
| 提前量 / 尾巴 | 按字幕时间重排整组（字幕条类不给提前量，它自己按字幕起落） |
| 重置整组 | 字号 / 位置 / 不透明度回到刚换装时的基准 |
| 全部关掉 / 全部打开 / 删掉整组 | 预览对比、推倒重来 |

### 单独换一句 / 换模板不丢字

字幕页往下，每一句一行：左边是台词，右边下拉直接换**这一句**的样子，其它句不动。

在「图层」页用那个「模板」下拉换样式时，**台词会跟着搬过去** —— 这件事以前是丢的：
同一句话在不同模板里叫不同参数（字幕条的字在字幕轨上、卡点大字在 `text`、编号卡片在 `items`、
终端在 `lines`、吊牌在 `product`……），直接换 id 的话新模板读不到参数，画面上那句词就没了。
现在换之前先把文本抠出来，换完写进新模板对应的参数里，顺带把位置 / 颜色 / 强调色也带过去
（会把 `> ` 这类装饰和跑马灯的序号前缀清掉）。

字号**不**跟着走：各模板的字号不是一个量纲（字幕条 44、卡点大字 118），搬过去只会把版式弄坏 ——
和「整组改」用倍数是一个道理。

## 素材剪辑时间线（视频 / 图片 / 音频）

时间轴上现在是**一条条片段**，不再是"一个视频 + 一支音乐"：

![素材剪辑时间线](docs/preview-clips.png)

| 能做 | 怎么做 |
| --- | --- |
| 加素材 | 顶栏 `载入视频 / 图片` / `载入音频`，或者把文件直接拖进画面区 |
| 挪位置 | 拖片段本体（会吸附播放头、工程两头、别的片段边缘） |
| 裁剪 | 拖片段**左右两边的白条** —— 左边改入点和起点，右边只改长度，都不会超过素材本身 |
| 切开 | 播放头挪到要切的地方，按 **`S`**，或者右栏「剪辑 → 在播放头切开」 |
| 复制 | 「复制一段接在后面」——切开 + 复制拼出一段循环很方便 |
| 删除 | 选中片段按 `Del`（没选片段时 `Del` 删的是图层） |
| 精确改数值 | 右栏「剪辑」页：起点 / 时长 / 入点 / 音量 |
| 改工程时长 | 片段排到哪儿时长就长到哪儿（手动改过时长就不跟了） |
| 变速 | 剪辑页「速度 ×」（0.25~4），或直接点 0.5× / 1× / 1.5× / 2× / 4× |
| 多轨叠加 / 画中画 | 剪辑页选「轨道」+ 缩放 + 位置 —— 轨号大的盖轨号小的 |
| 调色 / 滤镜 | 剪辑页 8 个预设（原片/暖调/冷调/高对比/褪色/黑白/磁带/反相）+ 亮度对比饱和度色相模糊 |
| 音频交叉淡化 | 剪辑页设「淡入 / 淡出」；两段音频叠在一起时接缝**自动交叉淡化** |

![多轨叠加 + 画中画 + 调色](docs/preview-pip.png)

> 上面这张：底轨 A-ROLL 铺满 + 轨 2 的 B-ROLL 缩到 34% 当画中画，两段各自有调色，
> 画中画还开了 1.5× 变速 —— 时间轴上那条片段右边会标出「轨2 1.5× 调色」。

几个说明：

- **变速**是"时间轴 1 秒吃掉素材几秒"。1.5× 的意思是素材 3 秒铺到时间轴上只要 2 秒。
  预览会真的用 `playbackRate` 放，导出时逐帧 seek 到正确位置，所以变速不会让声音和画面对不上。
- **多轨叠加**现在有 4 条视频轨（0~3）。同一条轨上是"后面盖前面"，轨号大的盖轨号小的。
  想做画中画：轨号调到 2，缩放拉到 0.3 左右，再用左右 / 上下位置挪到角上。
- **调色**走的是 canvas 的 `ctx.filter`，所以预览、导出、无头渲染三边完全一致 ——
  不会出现"预览调好了、导出跑偏"这种事。
- **交叉淡化**不用手动算：两段音频在时间轴上叠一点，重叠多少就淡化多少，
  接缝处不会有"啪"的一声。想更长就再叠多一点，也可以手动加淡入/淡出。

**时间轴缩放 / 横向滚动**（素材一多，整条铺满就没法看了）：

| 操作 | 效果 |
| --- | --- |
| 工具栏 🔍+ / 🔍− | 放大 / 缩小（以画面中心为锚点） |
| `Ctrl`（或 `Alt`）+ 滚轮 | 以**鼠标位置**为中心缩放 —— 想看清楚哪一段就冲哪儿滚 |
| `Shift` + 滚轮 | 左右平移 |
| 工具栏 ⤢ | 整条铺满（回到默认） |
| 播放时 | 放大之后播放头跑出可见区，时间轴自己跟着滚 |

放大以后标尺会自动改刻度（20 秒的工程放大到 196%，刻度就从 2 秒一根变成 1 秒一根），
片段的缩略图和波形也跟着放大，裁切能对到帧。

![缩放后的时间轴](docs/preview-zoom.png)

**片段之间加转场**：同一轨上两段贴在一起时，接缝处会出现一个小方块（⋈），点它选效果 ——
也可以右栏「剪辑 → 加转场」。转场骑在切口上，前后各占一半（时长可调 0.2~2 秒）。

![转场选择](docs/preview-transition.png)

引擎里那 10 个转场模板（甩镜 / 冲击推近 / 镜头震动 / 闪白硬切 / 百叶窗 / 网点升起 /
扫描带 / 故障爆闪 / 遮幅推入 / 色散冲击）都能用。做法的说明：转场模板本来就是"盖在切口上的
一层效果"，所以画面在转场的**中点换段**，转场盖在上面把这一下遮住 —— 这样不用两路合成，
而且转场本身是一个真的图层（时间轴上能看到、参数面板能调、导出走同一套）。
片段挪了 / 裁了 / 删了，转场会跟着走。

时间轴上方有一排图标（照剪辑软件的习惯放的）：

![时间轴工具栏](docs/preview-toolbar.png)

| 图标 | 作用 | 快捷键 |
| --- | --- | --- |
| ↶ ↷ | 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`） |
| ✂ | 在播放头切开选中的片段 | `S` |
| ⧉ | 复制选中片段接在后面 | `Ctrl+D` |
| 🗑 | 删掉选中的片段（没选片段时删图层） | `Del` |
| 🧲 | 拖动片段时吸附播放头 / 相邻边缘 | 点亮 = 开 |
| 🔍+ / 🔍− / ⤢ | 时间轴放大 / 缩小 / 整条铺满 | `Ctrl`+滚轮 |

**撤销是"改完就能撤"**：每 350ms 比一次工程内容，变了就记一版（最多 60 步）。
拖动 / 框选过程中不记，一次拖拽只留一条；松手后 800ms 内的小改动并进上一条，
所以打字不会一个字留一条历史。在真正的文本框里 `Ctrl+Z` 还是浏览器自己的撤销。

要点：

- **素材和片段是两层**。同一份素材切三刀就是三个片段，各自有入点和长度 —— 剪映也是这么分的。
- **视频、图片、音频都能剪**。图片默认给 3 秒，拖右边随便改长；视频/音频裁剪到头就停住。
- **导出走的就是时间轴上的样子**。预览、无头渲染、导出的 MP4 是同一套引擎，
  按片段找素材、按入点取时间，所以"所见即所得"。
- **MP4 带声音时混的是整条时间轴**：每段音频 / 视频按自己的位置、入点、音量混进去
  （离线渲染，不受播放速度影响）。

还没做的（说清楚免得踩空）：关键帧动画（现在每段的位置/缩放是常量）、蒙版 / 裁剪、
画中画的圆角描边、降噪这类音频处理。转场只有画面轨有。

## 导出 & 接进剪辑软件

点右上角 `导出…`：

| 导出项 | 用途 |
| --- | --- |
| **PNG 序列（ZIP，含透明）** | 最通用。解压后一批 PNG 直接拖进任何剪辑软件 |
| **WebM（VP9 含透明）** | 一个文件搞定，Premiere 2020+ / 剪映可直接读 |
| **MP4（H.264 · 直接出片）** | 点一下直接下载一个能播的 `.mp4`，不用装 ffmpeg 也不用转码 |
| **ProRes 4444（.mov 含 Alpha）** | 画质最好，走本机 ffmpeg（见下） |
| **工程 JSON** | 保存 / 分享你的模板组合和全部参数 |
| **卡点标记** | txt 标记，导入 Premiere 后时间轴上是一条条卡点 |
| **字幕 SRT** | 导出当前字幕轨 |

弹窗下面有个开关：**"把底下的视频/图片一起渲染进去"**。
默认不勾选 = 只导出带透明的叠加层（剪辑时铺在上面）；勾上了就是直接把效果烧进画面。

### 直接出 MP4

**导出… → MP4（H.264）** 就完事：结束后直接下载 `motionkit_时间戳.mp4`。走的是 WebCodecs
（`VideoEncoder` / `AudioEncoder`）+ 自己的 MP4 封装器（[engine/mp4.js](engine/mp4.js)），
逐帧编码，合成结果和无头渲染是同一个引擎，不会"预览一个样、导出另一个样"。

两件要知道的事：

- **帧精确，导出多长就是工程多长**。这一点以前是错的：浏览器录屏（MediaRecorder）按
  **墙上时钟**给帧打时间戳，渲染一帧比 `1/fps` 慢的时候，2 分 40 秒的工程能导出成 6 分钟。
  现在每帧的时间戳是 `i/fps` 写在文件里的，而且不用等实时 —— **渲染多快就多快**。
- **可以带声音**。弹窗里那个「导出 MP4 时带上声音」默认开着：会把「载入音频」那一轨
  重新解码、编成 AAC（192k）封进同一个文件里，从 0 秒开始、长度跟着工程走。
  没载入音频、或者浏览器没有 `AudioEncoder` 时，自动出无声的 MP4，不报错。
  PNG 序列 / WebM / ProRes 那几项仍然只有画面。
- **没有透明通道**（H.264 就不支持），所以透明区域由程序**压成深色底**再编码 ——
  不然交给浏览器自己合，实测会变成浅灰，白字压上去直接看不清。
  想把实拍一起烧进去就勾上那个"把底下的视频/图片一起渲染进去"。

> 要"你自己剪好的片子 + 原声 + 叠加层"还是走另一条：
> `tools/encode.py --overlay 原片.mp4 --audio 音乐.wav`，或者 AI 助手跑 `--render`。

Firefox / Safari 目前没有 MP4 录制能力，这种情况下会直接告诉你改用 PNG 序列，
而不是给你一个后缀是 `.mp4`、其实打不开的文件。

> WebM（VP9 含透明）那条路还是**实时录制、无声**，渲染慢就把时长拖长 ——
> 要准的、要带声音的用 MP4，要透明的用 PNG 序列 / ProRes。

### 用 ffmpeg 编码 / 直接烧到成片

```bash
# PNG 序列 -> ProRes 4444（带 Alpha，PR / FCP / 达芬奇都认）
python tools/encode.py --in .out/frames --out ESCAPE.mov --codec prores4444 --fps 24

# PNG 序列 -> WebM VP9（带 Alpha，体积小）
python tools/encode.py --in .out/frames --out ESCAPE.webm --codec webm-alpha --fps 24

# 直接把叠加层烧到你的剪辑上，并配上音频
python tools/encode.py --in .out/frames --out final.mp4 --codec h264 \
    --overlay my_cut.mp4 --audio music.wav --fps 24
```

> ffmpeg 从哪来：优先用 `pip install imageio-ffmpeg` 自带的那份，其次找系统 PATH。
> 本机已经装了 `imageio-ffmpeg`，直接能用。

具体软件的导入步骤见 [docs/](docs/)：Premiere、剪映专业版、达芬奇、AE 各有一份。

## 命令行：无头批量渲染

不用打开界面，直接用本机 Chrome/Edge 逐帧渲染（零 npm 依赖，靠 Node 内置 WebSocket 走 CDP）。

# 渲染一个工程

## 写自己的模板

一个模板就是一个对象，看三个字段：`params`（自动生成右侧控件）、`draw`（画一帧）。

```js
// templates/my-effect.js
import { text, hudPanel, ui } from '../engine/draw.js';
import { envelope, color, P } from './_lib.js';

export const myEffect = {
  id: 'my-effect',
  name: '我的效果',
  category: 'overlay',              // overlay | typography | caption | panel | transition
  hint: '一句话说明，会显示在模板库和搜索里',
  params: [
    { key: 'title', label: '标题', type: 'string', default: 'HELLO' },
    { key: 'position', label: '位置', type: 'string', default: '0.5,0.5' },
    P.color('white'),
    P.accent('orange'),
  ],
  draw(ctx, env) {
    // env 里有：scene / t / local / duration / progress / params
    //          / rng（确定性随机）/ beat / beatPhase / beatIndex / caption / frame / fps
    const { width: w, height: h, params: p } = env;
    const a = envelope(env.progress, { inFrac: 0.1, outFrac: 0.1 });  // 自动进退场
    if (a <= 0.001) return;
    const [nx, ny] = String(p.position).split(',').map(Number);
    ctx.save();
    ctx.globalAlpha *= a;
    hudPanel(ctx, w * nx - 160, h * ny - 40, 320, 80);
    text(ctx, p.title, w * nx, h * ny, {
      font: 'Arial Narrow, sans-serif', size: 40, weight: 700,
      color: color(p.color, ui.paper), align: 'center', baseline: 'middle',
    });
    ctx.restore();
  },
};

export default [myEffect];
```

然后在 `templates/index.js` 里 import 进来、加进 `ALL`，跑一次 `npm run bundle` 就完事。

**几个约定**（照着做风格才会统一）：

- 图层默认画在**透明画布**上，别自己填满屏幕
- 用 `envelope()` / `envelopeByTime()` 做进退场，别硬切
- 随机一律走 `env.rng` 或 `trng(env)`，保证预览和导出逐帧一致
- 想要"跟着拍走"就用 `env.beatPhase`（距最近拍的时间差）和 `env.beatIndex`

`roundRect` `cornerTicks` `hudPanel` `microRow` `statBlock` `hbar` `ticker` `barcode` `dial` `crosshair`

## 已知限制 & FAQ

**刷新一下工程就没了？**

不会了。工作室会自动把工程存在浏览器本地：工程本身（图层 / 参数 / 变换 / 特效栈 /
字幕 / 卡点 / 分辨率帧率）存 localStorage，素材（视频 / 图片 / 音乐）存 IndexedDB。
改完什么都不用点——刷新、关掉浏览器、换一天再打开，都会自动接着上一次，
画面顶上会有一条「已恢复上次的工程」提示：**知道了** 收起来，**丢弃** 从空白重来。

两个边界要说清楚：

1. 单个素材超过 **120 MB** 就不一起存了（会提示你重新拖进来），工程本身照存不误。
   长视频想省事就自己留着原文件，工程在图层的都在。
2. 存的是**这台机器这个浏览器**里的本地数据。清浏览器数据 / 换机器 / 换浏览器 / 发给别人，
   都要用顶栏的 **保存工程** 存成 JSON 文件（打开工程 载回来）。
   另外用 `?render=1` 或无头渲染打开时不会读写这份存档，不影响批处理。

**双击打不开 / 白屏怎么办？**

**界面字太小 / 图标看不清？**

右栏「工程」页最上面选「界面大小」（小 / 标准 / 大 / 特大），整体一起放大，
包括时间轴上那些画在 canvas 上的字（它们不吃 CSS，是单独一套缩放）。
还可以顺手把左右两栏拖宽（分隔条），参数名会跟着换行更好认。

按这个顺序排查：

1. 用 `启动工作室.bat` 打开（它会挑 Chrome/Edge）
2. 还是白屏 → 说明浏览器不对。右键 `dist/studio.html` → 打开方式 → **Google Chrome**

**某个图层位置不对，或者想让它大一点 / 小一点？**

在预览里点一下它，选择框和手柄就出来了：拖动挪位置、拉四个角缩放、转上面那个圆手柄旋转、
双击直接改文字。挪到画面正中会自己吸住，并出现青色对中线。要够到被压住的层，按住 `Alt` 再点。
右侧「图层参数」里的 **复位变换** 能一键还原——它只清掉你手动摆的位移 / 缩放 / 旋转，
模板自己的 `位置` 参数不受影响。

这些变换是写进工程里的（存 JSON、导出、无头渲染都带着），所以摆完直接导出就行。
唯一的例外是**转场类图层**（`whip-pan`、`zoom-punch`、`flash-cut` 这些）：它们每一帧都是把
整个画面抓下来重组，本身就是"整帧效果"，拖动和缩放对它们没有意义。

**AI 助手点了没反应，或者提示「需要开发模式」？**

AI 助手要调 python、ffmpeg 和无头浏览器，只有带后端的开发模式才有。
双击 `dist/studio.html` 是纯前端单文件版，没有后端。改用一键启动：

**双击 `启动工作室.bat`**（或者 `npm run studio` → 打开 http://localhost:5178/studio/index.html），
然后顶栏点 **✨ AI 助手**。

面板顶上那行会告诉你环境缺什么（Python / ffmpeg / LLM / 字幕），缺了也不影响其它部分。
完全不用 LLM 也能跑，只是文案由本地规则生成。

**自动字幕要额外的 Key 吗？**

不用。这台机器已经装好 [faster-whisper](https://github.com/SYSTRAN/faster-whisper)
和 `small` 模型（463 MB，在 `C:\Users\<你>\.cache\huggingface\hub` 里），
**完全离线、免费**。实测 20 秒中文人声约 10 秒出结果。
唯一的取舍是模型大小：想更准就换 `medium`（越准越慢），详见
[agent/README.md](agent/README.md#本地字幕这台机器上已经装好)。

**AI 助手生成的不合口味？**

先调那两个滑杆：**幅度**管"狠不狠"，**密度**管"东西多不多"——这两个能解决八成的口味问题。
换 **配色风格** 是第二大杠杆。还想更细就让它在工作室里当草稿：工程载进来之后，
每个图层、每个参数都能继续改，跟手搓的工程没有任何区别。
它每次的判断和理由都写在输出目录的 `report.md` 里，先看那份比瞎调快。

**它会不会写出引擎不认的工程？**

不会。生成之后会拿 `agent/schema.json`（从 46 个模板导出的参数表）逐字段校验：
不认识的键丢掉、越界数字钳回范围、非法选项退回默认，越界的情况会记在 `report.md` 里。

**为什么导出的 PNG 这么大？**
颗粒（grain）是逐像素噪声，PNG 压不动。1 秒 1080p 大概 200–400 MB。
如果嫌大：把 `fx` 里的 `grain` 去掉，或者先导 ProRes 4444（有压缩且无损）。

**能出 4K 吗？**
能。工程设置里把宽高改成 3840×2160 就行。渲染速度约 2–4 帧/秒（看模板数量）。

**导出的时候要等很久？**
PNG 序列是逐帧起浏览器渲染的，1080p 大概 8–15 帧/秒。
导出时先弹一个保存框（Chrome 的 File System Access），选好路径后是**边渲染边写盘**，
不会把几百帧堆在内存里。

**转场模板为什么看不出效果？**
变换式转场（甩镜 / 推近 / 震动）需要底下有画面。如果没载入素材，它们会去快照一张空画布。
载入视频、或者用 `--media` 垫张图就能看到。

**卡点不准？**
先看时间轴上的卡点线跟波形对不对得上。差一点点的话，在右边"卡点"里微调 `偏移`（秒）。
差半拍的话把 `BPM` 乘 2 或除 2。乐器密集的曲子可以试着把 `--bpm-min/--bpm-max` 收窄。

**能用在 Premiere 里当面板吗？**
现在的形态是"工作室 + 通用文件导出"，所有剪辑软件都能用。
面板化（CEP/UXP）需要额外打包和签名，如果你确定要我可以再加一层壳。
