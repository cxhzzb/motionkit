# 命令速查

所有命令都在**工程根目录**（就是你 clone 下来的那个文件夹）下执行。

## 打开工作室

```bash
npm run studio          # http://localhost:5178/studio/index.html
```

或者直接双击 `dist/studio.html`（单文件版，不需要服务器）。

```bash
npm run bundle          # 改完源码后重新打包单文件版
```

## 无头渲染

```bash
# 整段渲染一个工程
node tools/render.mjs --scene presets/slopcore.json --out .out/slop --fps 24

# 单个模板试参数
node tools/render.mjs --template kinetic-type --duration 3 --out .out/kt

# 只要 1.0 ~ 2.5 秒
node tools/render.mjs --scene presets/slopcore.json --out .out/cut --range 1.0 2.5

# 垫底图（核对叠加层 / 转场）
node tools/render.mjs --scene presets/transitions-demo.json --media docs/sample-footage.jpg --out .out/trans

# 用打包好的单文件版
node tools/render.mjs --page dist/studio.html --scene presets/demo-scene.json --out .out/frames

# 4K 输出
node tools/render.mjs --scene presets/slopcore.json --width 3840 --height 2160 --out .out/4k

# 指定浏览器
node tools/render.mjs --template hud-frame --browser "D:\Chrome\chrome.exe" --out .out/hud
```

## 改完界面自己看一眼

```bash
# 截一张工作室界面（整页）
node tools/shot.mjs --out .out/ui.png

# 载入某个预设再截
node tools/shot.mjs --url "studio/index.html?preset=slopcore.json" --out .out/ui.png

# 用脚本驱动真实交互（点选 / 拖动 / 缩放 / 旋转 / 双击改文字）后截图，
# 顺便把关键几何量核对一遍，跑完会打印一份 checks 报告
node tools/shot.mjs --url "studio/index.html?preset=slopcore.json" \
  --js-file tools/ui-selftest.js --out .out/ui-selftest.png

# 打包好的单文件版也一样能测
node tools/shot.mjs --url "dist/studio.html?preset=slopcore.json" \
  --js-file tools/ui-selftest.js --out .out/ui-bundled.png

# 「刷新之后工程还在吗」：改工程 → 刷新页面 → 核对图层/参数/素材是否接回来
node tools/shot.mjs --js-file tools/ui-persist-test.js \
  --js-file2 tools/ui-persist-test.js --reload --out .out/persist.png

# 单文件版（file://）的存储行为跟 http 不一样，也测一遍
node tools/shot.mjs --url dist/studio.html --js-file tools/ui-persist-test.js \
  --js-file2 tools/ui-persist-test.js --reload --out .out/persist-bundled.png
```

`--js-file` 给的那段代码是在页面里执行的，可以直接用 `window.MotionKit` 那套接口
（`selectLayer` / `layerBox` / `setTransform` / `pickAt` / `openTextEditor` …）。

## 编码

```bash
# ProRes 4444，带 Alpha（推荐给 PR / FCP / 达芬奇）
python tools/encode.py --in .out/slop --out ESCAPE.mov --codec prores4444 --fps 24

# ProRes 422，不带 Alpha，文件小一些
python tools/encode.py --in .out/slop --out ESCAPE.mov --codec prores422 --fps 24

# WebM VP9 + Alpha
python tools/encode.py --in .out/slop --out ESCAPE.webm --codec webm-alpha --fps 24

# H.264 / H.265
python tools/encode.py --in .out/slop --out flat.mp4 --codec h264 --crf 16 --fps 24

# 直接烧到成片上，并挂上音频
python tools/encode.py --in .out/slop --out final.mp4 --codec h264 --overlay my_cut.mp4 --audio music.wav --fps 24
```

| codec | 用途 |
| --- | --- |
| `prores4444` | 带 Alpha，画质最高，专业软件通吃 |
| `prores422` | 不带 Alpha，体积小一半 |
| `webm-alpha` | 带 Alpha，体积最小 |
| `h264` / `hevc` | 不透明，直接当成品 |
| `png` | 再输出一遍 PNG 序列 |

附加参数：`--crf 16`（质量）、`--bg white`（不透明编码时的底色）、`--size 1920x1080`。

## 卡点分析

```bash
# 生成 JSON
python tools/beatmap.py --in music.mp3 --out beats.json

# 顺便生成 Premiere 能导入的标记
python tools/beatmap.py --in music.mp3 --out beats.json --markers beats.txt --fps 25

# 不吸附到起音峰（想要严格等分网格时用）
python tools/beatmap.py --in music.mp3 --out beats.json --no-refine

# 乐曲 BPM 范围很窄时收窄搜索，更准
python tools/beatmap.py --in music.mp3 --bpm-min 120 --bpm-max 140 --out beats.json
```

输出 JSON 里的 `beats` 就是每一拍的秒数，可以直接喂给你自己的脚本。

## 一键演示

```bash
npm run demo
# 等价于：渲染 6 秒 demo 场景 -> 编码成 ProRes 4444
```

## 故障排查

| 现象 | 处理 |
| --- | --- |
| `找不到 Chrome/Edge` | 加 `--browser "你的浏览器路径"` |
| 渲染卡住不动 | 多为本地端口被挡。确认没有代理软件拦截 `127.0.0.1` |
| `等待 MotionKit 初始化` 超时 | 打开 `studio/index.html` 看控制台报错 |
| `找不到 ffmpeg` | `pip install imageio-ffmpeg` |
| 编码出来是黑底 | 该格式不支持 Alpha，换 `prores4444` 或 `webm-alpha` |
| 卡点整体差半拍 | `tools/beatmap.py` 加 `--bpm-min/--bpm-max` 收窄范围 |
| 单文件版载入不了预设 | 重新 `npm run bundle`，预设是打包时内联进去的 |

## 换电脑 / 两台机器同步开发

**不用敲命令。** 开发模式（双击 `启动工作室.bat`）下，工作室顶栏有个 **⇅ 同步** 按钮，
点开就是一个全按钮的面板：

| 面板上的按钮 | 干什么 |
| --- | --- |
| 保存设置 | 名字 / 邮箱 / 仓库地址，填**一次**就行 |
| 提交并上传 | 自动把这次改动提交并推到 GitHub |
| 拉取最新 | 从 GitHub 拉最新（开工前点一下） |
| 打包给另一台电脑 | 生成一个 zip（不含 `projects/` 里的大片），拷过去解压就能接着干 |
| 复制公钥 | 复制 SSH 公钥，粘到 GitHub 的 Settings → SSH and GPG keys |

> 单文件版 `dist/studio.html` 是纯前端、没有后端，用不了这个面板；要用就双击
> `启动工作室.bat`。

仓库里放的是**代码**：引擎 / 模板 / 工作室 / 工具 / agent / 预设 / 文档。
不放干活的成片——`projects/` 整块被忽略（体积大、里面是真实素材和歌词），
`agent/config.json`（API Key）也忽略。所以换电脑后有两件事要自己补一次：

1. **`agent/config.json` 不在仓库里**（里面是 API Key，故意忽略）。换电脑后从
   `agent/config.example.json` 复制一份，把 key 填进去。
2. **`dist/studio.html` 是打包产物，但故意留在仓库里**（双击即用那个）。
   改了 `studio/` 下的源码后记得 `npm run bundle` 再提交，不然两台机器会来回覆盖它。

想同步某个工程（不是代码）用「保存工程」导出的 JSON——它很小，可以直接
`git add -f projects/我的工程/scene.json` 强制加进去。
