# 接进 Premiere Pro

三种方式，按你的习惯挑一种。**推荐方式二**，最省事。

---

## 方式一：PNG 序列（最稳，画质无损）

1. 工作室里点 `导出…` → **PNG 序列（ZIP，含透明）**
2. 弹保存框时选一个空文件夹，起名比如 `ESCAPE_overlay.zip`
3. 解压
4. Premiere 里：`文件 → 导入…`，选中**第一个 PNG**，勾上 **图像序列**
5. 把导入的素材拖到视频轨道 **V2**（V1 放你的实拍）

**要点**

- 导入前先把序列帧率设成和工程一致：`文件 → 项目设置 → 常规 → 时间轴` 改成 24 / 25 / 30
- Premiere 认 PNG 的 Alpha，叠上去就是透明的，直接就能看到效果
- 一长串 PNG 会占硬盘，几十秒的片子建议改用方式二

> 也可以先用 ffmpeg 转成 ProRes 4444 再导入，工程更干净：
> ```bash
> python tools/encode.py --in 解压目录 --out ESCAPE.mov --codec prores4444 --fps 24
> ```
> ProRes 4444 是带 Alpha 的，Premiere 原生支持，拖进去和普通素材一样。

---

## 方式二：WebM（VP9 含透明）—— 一个文件

1. `导出…` → **WebM（VP9 含透明）**
2. 得到一个 `.webm` 文件
3. 直接拖进 Premiere 项目，放到 V2 轨道

Premiere 2020 及以后版本能直接解 VP9 的 Alpha 通道。
如果你的版本比较老、叠上去是黑底，就用方式一或方式三。

---

## 方式三：直接把效果烧进画面（不想叠轨道）

导出时勾上弹窗底部的 **"把底下的视频/图片一起渲染进去"**，
或者先在 Premiere 里把剪辑导出成 `my_cut.mp4`，然后：

```bash
python tools/encode.py --in .out/frames --out final.mp4 --codec h264 \
    --overlay my_cut.mp4 --audio music.wav --fps 24
```

出来的 `final.mp4` 就是已经带效果的成片，直接丢回 Premiere 或上传。

---

## 把卡点导进 Premiere 时间轴

1. 工作室里点 `导出…` → **卡点标记**
2. 得到一个 `motionkit_beats_128bpm.txt`
3. Premiere：`窗口 → 标记`，在面板右上角菜单点 **导入标记**
4. 时间轴上立刻出现一条条 `BEAT 001` `BEAT 002`……

有了这些标记，你手动切镜头、放转场的时候就能直接对齐（Premiere 的吸附会贴在标记上）。

---

## 小技巧

- 把叠加层素材嵌套一次（`右键 → 嵌套`），再整体调速度 / 位置，比改一堆关键帧方便
- 想改颜色：在效果控件里给叠加层加 **Lumetri → 色轮**，或直接加 **色调** 效果
- 想慢放：右键 → `速度/持续时间`，Premiere 会重算帧，叠加上去不会掉帧
- 叠加层默认是 `正常` 混合模式；想要更狠的科技感可以试 `滤色` 或 `线性减淡`
