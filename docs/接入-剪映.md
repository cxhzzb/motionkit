# 接进剪映专业版

剪映对透明视频的支持是这样的：**推荐用 PNG 序列**，其次是用 ffmpeg 转出来的 **带 Alpha 的 MOV**。

---

## 方式一：PNG 序列（最推荐）

1. 工作室点 `导出…` → **PNG 序列（ZIP，含透明）**，解压
2. 剪映里：`媒体 → 导入`，选中**全部 PNG**（框选或 Ctrl+A）
3. 全选后拖到**主轨道上面一条轨道**
4. 如果被当成一张张图片排开，改成：先把它们拖到时间轴，然后 `全选 → 右键 → 新建复合片段`（部分版本叫"打包"）

**要点**

- 剪映专业版默认工程帧率可能不是 24，先在 `设置 → 性能` 或工程设置里对齐帧率，不然会有轻微卡顿
- 导入前确认 PNG 是带透明的（用看图软件打开应该能看到棋盘格）

---

## 方式二：带 Alpha 的 MOV

先用 ffmpeg 把序列转成 ProRes 4444：

```bash
python tools/encode.py --in 解压目录 --out ESCAPE.mov --codec prores4444 --fps 24
```

然后把这个 `.mov` 直接拖进剪映。
剪映专业版能读 ProRes 4444 的 Alpha 通道，叠上去自动透明。

> 如果叠上去是黑底，说明这个版本没读到 Alpha。
> 换 PNG 序列（方式一），或者用下面的"烧录"方式。

---

## 方式三：直接烧进画面

导出时勾上 **"把底下的视频/图片一起渲染进去"**，
或者把剪好的片子导出成 mp4，然后：

```bash
python tools/encode.py --in .out/frames --out final.mp4 --codec h264 \
    --overlay my_cut.mp4 --audio music.wav --fps 24
```

---

## 卡点：剪映的踩点

剪映自带的"踩点"（音频 → 踩点）和我们的分析是两套。两种玩法：

1. **用剪映的**：先把音乐拖进剪映，用它的"自动踩点"生成节奏点，
   记下几个关键时间点，回到 MotionKit 里把图层对齐（时间轴上能直接看到秒数）
2. **用 MotionKit 的**：在 MotionKit 里排好卡点图层，导出叠加层，
   音频在剪映里单独加，两边只要 BPM 一致就对得上

导出的 `motionkit_beats_*.txt` 里是 `时分秒:帧` 格式，
剪映没有直接导入标记的功能，但可以对照着看时间码手动对齐。

---

## 字幕

如果你只是想要**字幕文件**（不要动效），直接用 `导出… → 字幕 SRT`，
剪映里 `文本 → 智能字幕 → 导入字幕文件` 就能用。
